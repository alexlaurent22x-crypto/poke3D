# Human mesh source — MakeHuman

Source: https://github.com/makehumancommunity/makehuman
Revision: `a8bc2d54ff0ac92e78ff71431b1023eda42bf482`
Retrieved: 25 October 2026 via the platform HTTPS Git proxy.

Files from `makehuman/data/3dobjs`, `makehuman/data/rigs` and selected **young adult** targets from `makehuman/data/targets/macrodetails`.

These data assets are explicitly released under **CC0 1.0 Universal** in their source headers and MakeHuman's `LICENSE.ASSETS.md`, copied here as `LICENSE.CC0.md`. The full MakeHuman application code (AGPL) is not included or required. Original asset holders include Data Collection AB, Joel Palmius, Jonas Hauquier and Manuel Bastioni as stated in the corresponding file headers.

The four game GLBs under `assets/characters` are derivatives generated by `tools/build_characters.py` using Blender 4.3.2. Clothing, hair, eye geometry, jewellery, materials, seating poses and animation assembly are created for this project. No photo of a real person or commercial game asset is used. Only adult macro targets are included.

To regenerate: `blender --background --python tools/build_characters.py` from the project root. Blender is a development tool; players need only Godot and the committed GLBs. The source OBJ is not used by the game and is excluded from game exports.
